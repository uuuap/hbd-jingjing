# 🎂 เว็บเซอร์ไพรส์วันเกิด (Interactive Birthday Web App)

เว็บแอปสำหรับเซอร์ไพรส์วันเกิดคนพิเศษ ส่งเป็นลิงก์ให้กดเล่นบนมือถือหรือคอมพิวเตอร์ได้ทันที!

## ✨ ฟีเจอร์เด่น
1. **หน้าล็อกรหัสผ่าน (PIN Lock)**: ต้องใส่รหัสผ่าน 4 หลัก (ค่าเริ่มต้นคือ `1234`) ถึงจะปลดล็อกเข้ามาดูได้
2. **เป่าเค้กวันเกิดได้จริง (Interactive Cake)**: กดแตะที่เปลวไฟเทียน เทียนจะดับ มีควันลอยขึ้น พร้อมพลุกระดาษฉลอง
3. **เพลงวันเกิดอัตโนมัติ (Music Box BGM)**: บรรเลงเพลง Happy Birthday ใสๆ (เปิด/ปิดเพลงได้ที่มุมขวาบน)
4. **กล่องความทรงจำ (Polaroids)**: ใส่รูปถ่ายคู่หรือรูปแห่งความทรงจำ
5. **ซองจดหมายเปิดอ่านคำอวยพร**: กดแตะซองจดหมายแล้วมีจดหมายเลื่อนขึ้นมาพร้อมข้อความซึ้งๆ

---

## 🛠️ วิธีปรับแต่งข้อมูลเป็นของตัวเอง

เปิดไฟล์ `index.html` หรือ `script.js` ด้วย Text Editor ใดๆ:

### 1. เปลี่ยนรหัสผ่านเข้าเว็บ
เปิดไฟล์ [script.js](script.js) บรรทัดที่ 6:
```javascript
passcode: "1234", // เปลี่ยนเป็นวันเกิด เช่น "0512"
```

### 2. เปลี่ยนชื่อและข้อความอวยพร
เปิดไฟล์ [index.html](index.html):
- บรรทัดชื่อ: ค้นหา `<h1 class="target-name">` แล้วแก้ชื่อได้ตามใจชอบ
- ข้อความในจดหมาย: ค้นหา `<div class="letter-body">` เพื่อเปลี่ยนคำอวยพรจากใจคุณ

### 3. เปลี่ยนรูปภาพความทรงจำ
ค้นหาแท็ก `<img src="...">` ใน [index.html](index.html) แล้วเปลี่ยนลิงก์รูป หรือเอารูปมาวางในโฟลเดอร์นี้แล้วใส่ชื่อไฟล์ เช่น `src="myphoto.jpg"`

## 🌐 วิธีนำขึ้นเว็บเพื่อเอาลิงก์ไปส่งให้เพื่อน (ฟรี 100%)

### วิธีที่ 1: Netlify Drop (ง่ายที่สุดในโลก ไม่ต้องสมัคร ไม่ต้องพิมพ์คำสั่ง)
1. เข้าเว็บ [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. ลากโฟลเดอร์โปรเจกต์นี้ทั้งโฟลเดอร์ไปวางบนหน้าเว็บ
3. รอ 10 วินาที จะได้ลิงก์ (URL) ทันที เช่น `https://sweet-birthday-card.netlify.app` ส่งให้เพื่อนได้เลย!

### วิธีที่ 2: Vercel
1. เข้าเว็บ [https://vercel.com](https://vercel.com)
2. เชื่อมต่อกับ GitHub หรืออัปโหลดโฟลเดอร์โปรเจกต์นี้
3. กด Deploy จะได้โดเมนส่วนตัวสวยๆ ทันที
